# agent-skills

My reusable skills for Claude Code and other coding agents.

## Skills

- **idea-critic** — stress-tests an idea from the viewpoint of the user, the investor, and other key stakeholders.

## Use it in another project

Install with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
# this project only
npx skills add chapagainmanoj/agent-skills@idea-critic

# every project on this machine
npx skills add chapagainmanoj/agent-skills@idea-critic -g
```

Update later with `npx skills update`.
